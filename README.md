# BIOL 601 — Research Methods in Biosciences

Interactive, in-browser learning activities for the MSc course
(Molecular Life Sciences, Khalifa University). Each activity is a
self-contained web page — nothing is installed, saved, or sent.

**Open the activity hub:** https://wael-osman.github.io/BIOL-601---Research-Methods-in-Bioscience/

## Contents

| Week | Activity |
|------|----------|
| 1 | Spot the Science · Hypothesis Lab |
| 2 | Ethics Lab |
| 4–5 | Experimental Design Studio |
| 6 | Significance Explorer · Choose the Right Test |
| 7 | Data Quality Detective · Data Readiness Checker |
| 8 | Data Assessment Explorer |

The landing page (`index.html`) links every activity by week.
